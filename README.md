## Run Locally

This is a static website and does not require a build step.

1. Clone the repository:

   ```bash
   git clone https://github.com/Achyutaryaa/achyutaryaa.github.io.git
   cd achyutaryaa.github.io
   ```

2. Start a local server. For example, with Node.js:

   ```bash
   npx serve .
   ```

3. Open the local URL shown in the terminal.

You can also open `index.html` directly in a browser, although a local server is recommended for the best results.
